# bucu_radial

> Fast Radial Action Wheel with Pure Trigonometric SVG Layout for FiveM (Keybind F1 / Z).

---

## 🌟 Overview

`bucu_radial` provides an instant-access circular radial action menu built with pure mathematical SVG trigonometry, maintaining **0.00ms idle CPU usage** when closed.

## 📦 Features
- **Vehicle Controls**: Toggle engine, hood, trunk, interior cabin light, and doors.
- **Quick Clothing Toggles**: Put on or take off hat, glasses, mask, jacket, body armor vest, or backpack in one click.
- **Emotes & Emergency**: Sit down, lean against walls, surrender hands-up, or trigger a 911 dispatch beacon.
- **Partial Input Focus**: Character movement and camera rotation remain fluid while wheel is open.
